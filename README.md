A 3D mechanical keychain designed as a hollow gear with an engraved letter (A). Designed using Onshape for ultra-fast printing and practicality

## ✨ Design Features
* **Smart Engineering:** The "gear" shape was chosen to reflect the core engineering identity of the mechanics track.
* **Fast Printing (Under 15 Minutes):** The design is hollowed in the center (10 mm diameter circle) and has a thickness of only 2 mm. This ensures extremely fast printing times and reduces filament consumption.
* **Personal Touch:** A customized touch was added by engraving the letter (A) into the body of the keychain.
* **Practical Durability:** The mounting ring was designed with an 8 mm outer diameter and a 4 mm inner hole (as per the task requirements). This provides a solid 2 mm plastic wall that withstands daily use and keychain tension without breaking.

## 🛠️ Tools Used
* **Design Software:** Onshape (Cloud-based CAD)
* **Final Format:** STL (Standard format for 3D printing)

## 📋 Implementation Steps
The design was executed through the following CAD modeling steps:
1. **Importing the Reference:** Inserting a gear silhouette image to use as a dimensional and structural reference.
2. **2D Sketching:**
   * Drawing the main gear circle and the inner hollowing circle.
   * Drawing a single gear tooth and utilizing the **Circular Pattern** tool to ensure precise mechanical symmetry.
   * Drawing the outer keychain mounting ring.
   * Inserting a text box to write the letter (A).
3. **Extruding:**
   * Converting the 2D sketch into a solid 3D object with a **2 mm** thickness in a single extrusion step.
   * Applying an engrave operation (Extrude - Remove) for the letter (A) with a depth of **1 mm**.
4. **Exporting:** Extracting the final model in STL format with high resolution (Fine settings).
